# Breaking changes in v24

- Replaces `eslint-plugin-import` with `eslint-plugin-import-x`
  - `import/*` rule and disable-comment prefixes must be renamed to `import-x/*` (e.g. `// eslint-disable-next-line import/no-cycle` → `// eslint-disable-next-line import-x/no-cycle`)
  - The `import/resolver` setting is now configured via `import-x/resolver-next`, using resolver factories (`createTypeScriptImportResolver`, `createNodeResolver`) rather than the legacy `import-x/resolver` object format. This is required to get `eslint-plugin-import-x`'s caching/performance benefits — the legacy `import-x/resolver` format falls back to a slow compatibility shim.
  - `config.plugins.import` now refers to the `eslint-plugin-import-x` plugin object
